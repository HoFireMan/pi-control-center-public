        Evidence limits

        Read-only boundary

        • Repository groups use Git common-directory identity, not names, remotes, or directory proximity.
        • Git porcelain order identifies the main record; later records are linked worktrees.
        • Prunable is descriptive Git administrative metadata and does not imply safe deletion.
        • Dirty status exposes bounded counts only; file names, ignored files, and diffs are omitted.
        Read-only Git metadata · no create, remove, prune, move, lock, unlock, checkout, branch, commit, or cleanup operations
